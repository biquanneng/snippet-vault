# SnippetVault 0.5.0

## Highlights

- **Secrets and Temporary.** The Vault is now called **Secrets**, and the
  temporary workspace is called **Temporary**. Nothing about your data moves.
- **Tools, starting with JSON.** A new **Tools** tab opens a JSON tool in its
  own tab: format, minify, and unescape without losing number precision.
- **Stash the current page.** Press `Command/Ctrl+C` twice with nothing
  selected to keep the page link in Temporary.
- **A fallback shortcut for search.** `Ctrl+Shift+K` (`Command+Shift+K` on
  macOS) opens search when a site swallows double `Shift`.

## Changes

- **Renamed areas.** Vault → **Secrets**, temporary workspace → **Temporary**,
  and **Move to vault** → **Move to Secrets**. The name does not mean
  encryption: records are still stored as plaintext on this device.
- **Tools.** The in-page panel shows **Secrets | Temporary | Tools**, and the
  side panel has a **Tools** entry. Both open the same JSON tool tab, reusing it
  if it is already open. The tool formats, minifies, and decodes one level of
  escaping from a JSON string. Formatting only rewrites whitespace, so large
  integers keep every digit. Invalid input reports the line and column. Input
  stays in that tab's memory and is never saved or sent anywhere.
- **Stash this page.** With nothing selected, `Command/Ctrl+C` twice saves the
  page title and URL as a link record to the quick save target. It does not
  trigger inside text fields or on sites where quick save is turned off.
  Stashing the same URL again extends its expiry instead of adding a copy;
  **Undo** restores the previous expiry. The **Temporary** tab has a
  **Stash this page** button that does the same. Link records open in a new
  tab and copy their full URL; confirmations never show the full URL.
- **Double `Shift` is more reliable.** It now works while a Chinese or other
  input method is active, and it is detected before pages that stop key events
  at the document can block it. It still ignores text fields on purpose.
- **Fallback shortcut.** `Ctrl+Shift+K` / `Command+Shift+K` opens search like
  the toolbar icon, including tabs opened before an update and pages where only
  the side panel can open. Change it under `chrome://extensions/shortcuts`.
- **Current site first.** With an empty search, records from the site you are
  on are listed first; the rest keep their usual order.
- **Copy as…** Copy a record as a shell `export`, a `.env` line, a JSON field,
  or an HTTP header, with the value escaped. Header values with line breaks
  are rejected. The converted text is never saved.
- **Getting started.** The search panel shows a short guide the first time it
  opens; reopen it from **Getting started** in the side panel.

## Migration and compatibility

- No storage migration. Records keep their type, labels, sources, and expiry,
  and backups import and export exactly as in 0.4.0.
- No new permissions. The fallback shortcut is a standard extension command.

## Known limitations

- Double `Shift` cannot work on browser-internal pages, the Chrome Web Store,
  or while focus is inside an embedded frame. Use the toolbar icon or the
  fallback shortcut.
- If another extension already uses `Ctrl+Shift+K`, Chrome leaves the shortcut
  unassigned; set one under `chrome://extensions/shortcuts`.
