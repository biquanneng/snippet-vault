## 实施要点

**R1**：只改 `locales/*.json` 的展示值与对外文案，存储 `kind`、消息契约和 i18n key 名保持 `vault` / `workspace`；无 schema 迁移，备份行为不变。

**B18**
- 页内面板标签为「机密｜临时库｜Tools」。Tools 是独立视图状态，不进入 `SearchPanelKind`，不会向后台发送 `kind='tools'`；Tools 视图隐藏检索框、新建与刷新。
- 侧边栏主菜单新增 Tools 一级入口。两处都发送 `snippet-vault/open-tool`，后台打开 `/tools-json.html`；已打开时通过 `runtime.getContexts` 聚焦已有 Tab（不使用 `tabs.query({url})`，因为无 `tabs` 权限时其 `url` 过滤会被忽略）。
- JSON 工具使用 CodeMirror 6（未采用 Monaco：体积与 MV3 Worker 配置成本更高）。格式化/压缩由 `lib/json-tool.ts` 的迭代式 token 扫描完成，原样复制 token，只改写结构空白；去转义只接受完整合法的 JSON 字符串字面量（引号可省略）。输入上限 10 MB，格式化输出上限 64 MB（防止深层嵌套缩进膨胀）；超过 256 KB 时先渲染处理中状态。内容只在该 Tab 内存中，不读剪贴板、不保存、不记录、不发 GA4。

**B19**（防御性修复，见下方记录）
- `DoubleShiftDetector` 识别输入法激活时 `key: "Process"` / `keyCode 229` 且 `code` 为 `ShiftLeft`/`ShiftRight` 的按键。
- 监听从 `document` 捕获阶段移到 `window` 捕获阶段。
- 新增 `chrome.commands` 命令 `open-search-panel`（建议 `Ctrl+Shift+K` / `Command+Shift+K`），复用工具栏的补注入与侧边栏回退路径，不新增权限。
- 可编辑区域内继续屏蔽双 Shift（维护者确认保持既有行为）。

**B20**
- 无选区、焦点不在可编辑区域、页面为 HTTP(S) 时，双 Cmd/Ctrl+C 发送 `snippet-vault/save-page-link`；有选区时行为不变。QuickSave 在快捷保存例外页面不挂载，因此自动遵守例外设置。
- 后台只信任 `sender.tab` 的 URL 与标题，正文为 `[title](<url>)`（尖括号目标，避免 URL 中的 `)` 截断链接）。去重只匹配此前暂存的链接记录，同页的普通选区片段不参与。目标库跟随快捷保存目标；临时库中同一完整 URL 的未过期记录按现有规则延期（`outcome: 'extended'`），撤销通过新增的 `snippet-vault/restore-workspace-expiry` 恢复原有效期；机密中已存在时返回 `duplicate`。保存请求串行化，避免并发重复。
- 面板临时库标签提供「暂存当前页」按钮，**固定写入临时库**（偏离 PRD「与入口一相同」，理由：按钮位于临时库标签，跟随目标写入机密会让结果不可见；待维护者确认）。
- 链接记录（正文为 `[…](<source.url>)` 且为 HTTP(S)）的复制使用完整 URL，并提供「打开」操作；Toast 不展示 URL。
- 未新增「链接」类内置标签（PRD 为可选；新增内置标签涉及标签目录与本地化，留待后续）。

**B11**：仅空查询浏览路径生效，`source.domain`（缺省时解析 `source.url`）与发送方 Tab hostname 严格相等的记录在分页前置顶，其余保持原排序；无发送方 URL 时不变。

**B12**：`lib/copy-formats.ts` 提供 raw / Shell export（单引号，变量名校验）/ .env（按值选用单引号、反引号或双引号，保证 dotenv 原样读回；三种引号都含时拒绝）/ JSON 字段 / HTTP Header（RFC 7230 token 名称，值含 CR、LF、NUL 拒绝）。结果项「按格式复制」菜单可填写名称，默认取首个标签名转大写下划线。

**B14**：首次安装后由后台在新标签页打开引导页 `welcome.html`（机密、临时库、Tools、两个快捷键与兜底键），「知道了」关闭该标签页；更新扩展不再打开。侧边栏「使用引导」可再次查看。

## B19 排查记录

- 复现：未取得受影响网址或浏览器复现环境；本轮未执行浏览器调试（需维护者授权）。
- 依据源码与 PRD 假设处理的失效层级：
  - B「未收到 keydown」：站点在 `document` 捕获阶段阻止传播 → 改为 `window` 捕获。站点若在更早注册的 `window` 捕获监听中 `stopImmediatePropagation`，仍可能失效，此时使用兜底快捷键。
  - C「被规则过滤」：输入法激活时 Shift 报告为 `Process` → 已兼容。
  - A「内容脚本未运行」：扩展更新前已打开的标签页 → 兜底快捷键与工具栏图标都会补注入。
  - E「权限边界」：浏览器内部页、商店页、iframe 获焦 → 不承诺支持，兜底键在受限页打开侧边栏。
- 未验证：400ms 阈值、宿主 dialog/inert、SPA 生命周期等其他假设。
- 待办：维护者按复现矩阵（普通页、SPA、编辑器、iframe、Shadow DOM、更新前已打开页、受限页、输入法开/关）在 Chrome 中验证修复前后表现。
