把经常需要的开发片段留在手边。

SnippetVault 是一款本地优先的 Chrome 扩展。它可以保存网页选区或手动输入的
AccessKey、Token、接口地址、命令和笔记，并在需要时快速找回来。

✨ 保存，无需填写

- 在网页中选中内容，按两次 Command/Ctrl+C。第一次是浏览器的正常复制，第二次
  会把选区保存为 Markdown，并记录页面标题和 URL。
- 保存后的提示提供“撤销”“转为保管库”，也可以在当前页面或网站停用快捷保存。
- 在本地自动识别常见凭据格式并打上标签：AWS 和阿里云 AccessKey ID、GitHub
  Token、JWT、sk- 开头的 API Key、PEM 与 SSH 密钥、数据库连接串。
- 也可以通过“新建”保存文本或 Markdown 片段，它会记录你当时所在的网页，保存前
  可以移除来源。

🔎 快速找回

- 在网页中双击 Shift，或点击工具栏图标，直接在当前页面打开检索。
- 搜索正文、标签和来源，并直接复制、编辑或删除结果。
- 保管库的检索结果按来源网站分组展示。

⏳ 临时工作区

- 快捷保存默认进入临时工作区。短期片段可以自动过期、按需延期，或者转入保管库
  永久保存。

🔒 默认留在本地

- 无需账号，不连接云同步或 AI 服务。匿名使用统计默认关闭，且绝不会包含保存的
  数据或搜索词。
- 片段保存在扩展自己的 IndexedDB 中。
- 备份为可读的 YAML 文件，默认使用口令加密（AES-256-GCM），也可以选择明文导出。
- 浏览器中保存的记录没有加密。SnippetVault 不是密码管理器，也不是加密的机密
  保险库。

支持 English 和简体中文，并提供浅色和深色主题。
