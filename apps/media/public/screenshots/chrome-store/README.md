# Chrome Web Store screenshot inputs

Provide one sanitized PNG for each filename below. English and Simplified
Chinese screenshots must be captured separately; do not mix languages inside a
single image.

```text
en/01-search.png
en/02-capture.png
en/03-in-page-search.png
en/04-temporary-workspace.png
en/05-local-backup.png
zh-CN/01-search.png
zh-CN/02-capture.png
zh-CN/03-in-page-search.png
zh-CN/04-temporary-workspace.png
zh-CN/05-local-backup.png
```

The renderer accepts any useful source dimensions and places the screenshot
inside a fixed marketing frame. Final cropping and positioning should be tuned
after the real images are available.

Before adding an image, verify that it contains only synthetic data and no real
credentials, domains, project names, email addresses, local file paths, source
URLs, or readable backup content.
